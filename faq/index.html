常见问题（FAQ）

答案来自批准事实；未公开的数值会明确标为未知，而不是补写猜测。

身份与基础信息

游戏的官方名称与 ID 是什么？
官方名称是 Build Base to Survive VERITY。Place ID 为 116070952245255，Universe ID 为 10604772590。
开发者是谁？
Roblox 群组 Danvd's Larpductions（群组 ID 1040399903）。群组接口显示 owner 用户名为 jirachi_eye，显示名为 Jirachi。
一个服务器最多多少人？
Roblox 游戏接口返回的 maxPlayers 是 6。官方描述还说明可以邀请好友一起建设基地。
角色类型是什么？
游戏接口返回 universeAvatarType 为 MorphToR15。
本站也讲其他同名作品吗？
不讲。本站范围只由上面的官方名称、Place ID、Universe ID 和开发者群组确定；不要把其他作品的攻略套到这里。
同一开发者还有相似游戏吗？
Roblox 群组游戏接口显示同一群组还发布了 Build Base to Survive MOBS（Universe 10697510253，Place 107999130556469）。这是另一款体验，不要混用资料。

玩法与保存

基地会自动保存吗？
官方描述写明建筑会自动保存。界面截图还显示 Save 按钮，但现有来源没有解释这个按钮与自动保存的具体关系。
VERITY 什么时候出现？
官方描述只确认 VERITY 在夜间出现。没有可靠来源公布精确昼夜时长。
可以和朋友一起玩吗？
可以。官方描述说明可以邀请好友一起建设同一座基地。
Rebirth 有什么奖励？
截图只证明 Rebirth 按钮存在。花费、重置内容、奖励和倍率都没有可靠来源，请以游戏内当前说明为准。
有徽章或子场景吗？
Rolimon's 在 2026-08-26 的追踪页显示没有已知徽章，也没有已知子场景。游戏更新后需要重新确认。

代码与消费

代码在哪里兑换？
打开左侧 Store，找到 Codes 输入区，粘贴代码并按 Enter。Pocket-Codes 把这个路径写为 PC 与移动端均可使用。
为什么代码没有生效？
先检查大小写和拼写。来源记录的错误提示是 “That code does not exist”，重复兑换提示是 “You already redeemed that code”。代码也可能在快照发布后过期。
2026-08-25 的代码快照有哪些？
THXFOR1M、CURIOSITYUPD、10000PLAYERS 与 CODES。具体奖励见首页代码区；当前状态必须在游戏内重新确认。
现金有什么用途？
Sportskeeda 把现金列为主要货币，并说明它可用于不同物品和枪械箱。
付费项目价格会固定吗？
不会这样承诺。新手教程只列出 Rolimon's 于 2026-08-26 显示的价格快照，购买前要重新核对。
